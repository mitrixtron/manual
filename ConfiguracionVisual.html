Configuración Visual

Configuración del Sistema ››

El estilo visual de BRUSH está definido principalmente mediante CSS. La personalización se realiza directamente en el archivo index.html en la sección <style> o mediante clases utilitarias.


Las configuraciones principales son:

✔ Degradado de fondo

En el <body> se puede modificar la clase:

<body class="bg-gradient min-h-screen">

La clase .bg-gradient está declarada como:

.bg-gradient {

    background: linear-gradient(135deg, #1e3a8a, #64748b);

}

Puedes cambiar los colores para personalizar la identidad de la plataforma.

✔ Tipografías

Actualmente, BRUSH utiliza:

Times New Roman para texto general

Tipografía estilizada para el logo “BRUSH”

Puedes cambiar la fuente global en el <style>:

body {

    font-family: 'Times New Roman', serif;

}
