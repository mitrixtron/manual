Estructura del Código

La estructura del código de BRUSH está diseñada para ser compacta, clara y fácil de comprender, ya que todo el sistema funciona dentro de un único archivo HTML que integra la interfaz, la lógica y la configuración. Esta organización favorece el desarrollo académico y la comprensión técnica del proyecto sin necesidad de frameworks complejos.

A continuación se explica cómo está organizado el proyecto a nivel de archivo, secciones internas y componentes de código.
