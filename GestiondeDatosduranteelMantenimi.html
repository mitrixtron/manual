Gestión de Datos durante el Mantenimiento

Mantenimiento ››

Como BRUSH usa LocalStorage, se debe tener cuidado al:

✔ Limpiar datos

Solo borrar LocalStorage cuando sea necesario:

localStorage.clear();

✔ Prevenir saturación

Las imágenes guardadas en Base64 pueden ocupar más espacio del previsto.

✔ Hacer respaldos

Exportar manualmente los datos antes de actualizaciones grandes:

JSON.stringify(localStorage.getItem("obras"))
