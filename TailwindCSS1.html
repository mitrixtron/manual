Función en el sistema:
Es la librería principal de estilos utilizada para diseñar la interfaz de BRUSH. Mediante clases utilitarias, permite aplicar estilos directamente en el código HTML sin necesidad de un archivo CSS separado.

Justificación de uso:

Estilo minimalista y moderno

Totalmente responsivo desde el inicio

Permite construir interfaces rápidas sin escribir reglas CSS personalizadas

Ejemplos de uso dentro del sistema:

Fondos con degradado azul-gris

Botones interactivos

Cuadrículas del feed

Modales estilizados

Tarjetas de publicaciones
